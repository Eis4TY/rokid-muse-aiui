# 先读我：0.3.1 像素头像版

这是完整文件夹，含 Skill、配对 APK、AIUI AIX 和安装脚本。保持文件结构，不要只发送单个 AIX。

1. 连接眼镜 USB，开启开发者模式与 USB 调试，在眼镜确认调试授权。
2. 在电脑安装 Python 3、adb、aix-cli；具体见 references/快速上手.md。
3. 在本文件夹打开终端，运行 `python3 scripts/setup.py setup`，或使用系统对应启动入口。
4. 新眼镜按提示填写**自己的** SDK token，并完成手机配对；已有像素版授权会保留。
5. 配对前在手机蓝牙设置忽略眼镜；配对后关闭 VPN 用 Rokid App 回连，回连成功再开启 VPN（非美国地区）。
6. 运行 `python3 scripts/setup.py open`，长按说话、单击结束、选择发送。看见真实回复才算完成。

无需六位交接码。运行时使用 Rokid 手机网络，不需要电脑保持连接。Windows 的 Python 命令可能是 `python`。

升级说明见 references/升级说明.md。
