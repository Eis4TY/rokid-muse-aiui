# 开发与验证（0.3.1）

## 分层

- Android 原生：独立设备身份、BLE/GATT v5、手机确认、Keystore 加密、挑战/HMAC/AES-GCM 本机交接。交接确认后只保留回执。
- AIUI：muse.phone.pairing.v1 保存设备授权，自动验证/重试交接，手机通道 HTTPS 与 WebSocket、Noise、会话注册、主会话订阅、录音 WAV 和回复显示。
- USB 安装器：预构建包校验、稳定应用 ID 与新 VERSION 分离、蓝牙权限、短时随机绑定密钥和解绑 reverse。不会导入电脑上的账号令牌。

升级保持应用 ID 与设备私有存储。

## 重构建

源码工程运行 `python3 scripts/build-release.py` 构建完整包；开发部署运行 `python3 scripts/deploy-phone.py --serial 实际序列号`。APK 构建依赖 macOS JDK / Android SDK Platform 31、Build Tools 35.0.0，Java 依赖使用阿里 Maven 并核对 SHA-256。已有用户无需编译。

直接修改随包源码时：

```sh
cd assets/source
sh native-pairing/build.sh
```

把生成 APK 复制到 assets/releases，再在 Skill 根目录运行：

```sh
node scripts/build-aix.cjs assets/source assets/releases/muse-aiui.aix
python3 scripts/setup.py --dry-run
python3 -m unittest discover -s scripts -p 'test_*.py'
```

不要直接 aix install 单个 AIX：该 CLI 会把 VERSION 当作应用 ID。使用 setup.py 的 prepare → push → apply → status 流程，启动使用公开源码目录里的稳定 .aix/agent-id。每次打包更新内部 VERSION，包含图标 assets、页面、JS 加密模块和许可证。

## 测试

`cd assets/source && npm test` 不需要 npm 依赖。50 项 JS 测试覆盖像素渲染、录音、回复关联、自动交接、身份不匹配拒绝、云端失败保留授权、回执丢失、旧异步刷新与旧 401 保护。15 项 Python 安装/诊断测试覆盖包校验、绑定与 reverse 清理、广播失败及脱敏。

原生 tests/test_pairing.py 需本地官方 muse-gadget-sdk 源码与 cryptography 环境；校验握手规范化、P-256/HKDF、AES-GCM 与重放拒绝，org.json 测试依赖从阿里源下载并校验哈希。源码快照不捆绑账号信息或 SDK 仓库。

自动测试不代表每个型号实测。保留授权升级、本机自动交接、从零手机配对和真实回复要分别记录，详见根目录版本说明。
