# 从零连接 Rokid 眼镜与 Muse

你需要：支持 AIUI 和 BLE 广播的 Rokid 眼镜、USB 数据线、Windows 电脑或 Mac、已登录 Muse 的手机，以及能连接眼镜的 Rokid 手机 App。电脑只用于首次安装；配对后日常无需电脑。

## 1. 准备工具（只做一次）

已经有 `adb`、`aix`、`python3` 就跳过本步。没有时，Mac 按下列步骤检查；Windows 工具安装与检查见根目录 [远程测试说明](../远程测试说明.md) 的“准备”部分：

```sh
adb version
aix install --help
python3 --version
```

ADB 可从 [Android 官方 Platform Tools](https://developer.android.com/tools/releases/platform-tools) 下载 Mac 版并加入 PATH；也可在已有 Homebrew 的电脑执行 `brew install --cask android-platform-tools`。Python 3 可用 [Python 官方安装包](https://www.python.org/downloads/macos/)。安装 [Node.js](https://nodejs.org/) 20 或更高版本后安装本方案验证过的 CLI，依赖优先用阿里 npm 镜像：

```sh
npm install -g @yodaos-pkg/aix-cli@0.10.1 --registry=https://registry.npmmirror.com
```

## 2. 连接并安装

眼镜开启 USB 调试，用数据线连接电脑，在眼镜允许调试授权。解压完整 skill 文件夹。Windows 双击 **开始配对.cmd**；Mac 双击 **开始配对.command**。也可在终端进入该文件夹运行（Windows 用 `py -3` 替换 `python3`）：

```sh
python3 scripts/setup.py setup
```

首次会提示粘贴 Muse SDK token。到 [Muse SDK Tokens](https://gadgets.muse.ai/settings/sdk-tokens) 登录自己的账号创建并复制；终端输入不会显示字符，粘贴后按回车。它是 SDK 开发者标识，手机配对稍后才产生账号访问授权。

**请使用完整 skill 文件夹和一键脚本安装，不要只将 AIX 单独交给 `aix install`。** 脚本会保持原应用 ID，同时用新的代码版本更新运行缓存。

脚本安装 **Muse 配对组件（APK）** 和 **Muse 眼镜 Demo（像素头像版）（AIX）**，自动建立本机交接绑定。记录终端显示的广播名，例如 `MuseGadgetXXXXXX`；每台设备身份不同。已有安装则沿用身份和授权。

如果你已经使用像素头像版且有有效授权，安装会直接启动，跳过第 3、4 步。升级方式见 [升级说明](升级说明.md)。

## 3. 手机确认配对

1. **先在手机系统“设置 → 蓝牙”中找到眼镜原有连接，选择“忽略此设备 / 取消配对”。仅断开连接不够。**
2. 手机 Muse App 打开 **Developer mode → Add Device**。
3. 选择终端显示的广播名称，点继续并确认绑定。
4. 眼镜显示“手机授权已收到”。如果出现网络选择，当前 demo 使用已有连接，不会真正配置所填 Wi-Fi。

搜不到时：确认已在手机系统蓝牙设置中忽略眼镜原有连接，保持 USB，重新扫描。配对窗口超过 10 分钟可运行：

```sh
python3 scripts/setup.py pair
```

## 4. 自动保存授权

按顺序恢复连接和网络：

1. **关闭手机 VPN。**
2. **通过 Rokid App 回连眼镜**，等待连接成功；此时不要开启 VPN。
3. **非美国地区：回连成功后再开启手机 VPN，使用眼镜 Muse AIUI 期间保持 VPN 开启。**
4. 打开 AIUI，自动验证并保存授权。

双击启动的用户此时在终端按回车即可打开 AIUI；使用命令行的用户运行：

```sh
python3 scripts/setup.py open
```

AIUI 会自动取得眼镜原生组件收到的新授权，联网验证后保存。**不用输入交换码、复制访问令牌或导入账号文件。** 若刚恢复网络，等待自动重试；保持 AIUI 在前台等待重试。

## 5. 判断成功与日常使用

日志 `native.auto cloud_verified=true` 与组件 `delivered=true` 表示新授权已验证和保存；普通使用以在线图标及真实助手回复为准。此时可以拔掉 USB，日常在眼镜打开 **Muse 眼镜 Demo（像素头像版）**，保持 Rokid 手机连接和手机网络可用。**非美国地区使用时，手机还需保持 VPN 开启。**如果需要重新回连 Rokid App，先关闭手机 VPN，回连成功后再开启。

“已配对 / Muse 云端连接中”只代表授权存在。只有显示 **Muse 在线** 并收到真实回复才代表会话可用。旧版配对及 0.3.0 像素版回复已有实测；本次 0.3.1 升级验收见版本说明，其他型号仍需验证。

重新配对：手机 Muse 移除对应 Gadget → 手机系统蓝牙设置忽略眼镜原有连接 → 连接 USB 运行 `pair` → 手机 Muse 重新确认 → 关闭手机 VPN、用 Rokid App 回连 → 非美国地区开启并保持手机 VPN → `open`。保留组件数据即可沿用原设备身份。

这不是官方 Android 配对发行版，是基于 [Meta Muse Gadget SDK](https://github.com/facebookincubator/muse-gadget-sdk) 协议实现的实验组件；其他 Rokid 型号需要支持 Android BLE peripheral/GATT server、Android 8+ 和 AIUI 引擎 >=0.17.0。

## 旧包显示交接码 / 更新后仍是旧界面

使用本次 0.3.1 完整 skill 包，保持 USB 连接运行 `python3 scripts/setup.py setup --rebind`，再 `python3 scripts/setup.py open`。本操作保留设备身份和已有账号授权，不要求先重新手机配对。新版不再提供交接码输入；未授权时会显示自动绑定或授权接收的提示。

请让调试人员确认运行日志含 `"event":"loaded","release":"0.3.1"`。如果仍出现旧提示，应先解决旧包/缓存问题，不能反复重新配对代替代码升级。升级后若已有待交接授权，恢复正确手机连接和 VPN 顺序，AIUI 会自动重试；只有明确授权失效才需重新 Muse 配对。
