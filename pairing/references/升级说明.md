# 升级与授权保留

## 已经安装像素头像版（b897…）

运行 setup。原应用 ID、眼镜身份和 AIUI 已刷新的令牌保留；首次整合时重新建立该应用的安全绑定，不撤销账号配对。不会用原生旧副本覆盖 AIUI 令牌，也不会误开启手机配对广播。

## 手动重新配对

确定用户确实要重配，再在手机 Muse 移除旧 Gadget；手机设置忽略眼镜原蓝牙连接 → setup.py pair → 手机 Muse 确认 → 关闭 VPN / Rokid 回连 → 非美国地区开启 VPN → setup.py open。新授权验证成功才替换旧授权；失败保留旧记录与待交接原生记录。

## 绑定故障

setup --rebind 只修复原生组件与 AIUI 的本机绑定，不清除 Muse 授权。若有其他旧 AIUI 应用，之后不要继续让它使用旧绑定接收新授权；后续统一使用像素版。
