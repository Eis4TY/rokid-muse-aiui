# Muse AIUI 0.3.1 远程测试

本版沿用旧版已验证的回复接收修复：默认发送到账号主会话，兼容缺少父消息 ID 的真实增量回复。已包含原生蓝牙名称竞态修复。保留身份、应用 ID 和授权，无需交接码。

## 准备（约 2 分钟）

1. 将压缩包完整解压到本地文件夹；建议路径简单，例如 `C:\MuseTest`。
2. 保持眼镜 USB 连接电脑并允许 USB 调试。
3. 电脑需要 Python 3、Node.js 20+、adb、aix-cli 0.10.1。已有工具无需重复安装。Windows 终端检查：

```bat
py -3 --version
adb devices
aix install --help
```

Python 可从 https://www.python.org/downloads/windows/ 安装，Node.js 从 https://nodejs.org/ 安装。ADB 下载官方 Windows Platform Tools：https://developer.android.com/tools/releases/platform-tools ，将 platform-tools 目录加入 PATH。安装 aix：

```bat
npm install -g @yodaos-pkg/aix-cli@0.10.1 --registry=https://registry.npmmirror.com
```

若没有 `py` 命令，下文把 `py -3` 换成 `python`。多台设备同时连接时拔掉其他设备，或在 Python 命令末尾加 `--serial 实际序列号`。


## 已配对：升级并测一次

1. 完整解压；打开“开始远程测试”，选 1，保留授权增量升级。若签名冲突停止，不卸载。
2. 选 5 打开 main。确认像素头像界面、在线图标和日志 loaded release=0.3.1；界面不以 DEV 数字判断包版本。
3. 选 4 开始 120 秒持续诊断。提示开始后，长按说“请只回复：测试通过”，结束录音后选择发送，只发一次。
4. 记录眼镜是否显示真实助手回复，手机主会话是否出现对应消息及助手回复；等待诊断结束，回传 results ZIP 和两边截图。

默认使用手机账号主会话，会话内容共享；每台设备身份与授权独立。日常不要选择旧 official 侧会话对照模式。0.3.0 的手机通道曾在 RG_glasses 验证真实回复；0.3.1 的安装、交接和配对分别按版本说明验收，其他型号仍需实测。

```bat
py -3 scripts\setup.py setup
py -3 scripts\remote_test.py open --profile main
py -3 scripts\remote_test.py watch --seconds 120
```

Mac 将 py -3 换为 python3。每次 watch 每两秒保存报告，中途停止也可回传已有 ZIP；不自动发送消息。

## 首次配对

使用“开始配对”。手机系统蓝牙忽略眼镜原连接 → Muse Developer mode / Add Device 确认实际 MuseGadget 名称 → 关闭 VPN → Rokid App 回连 → 非美国地区开启 VPN → open。具体见先读我与快速上手。脚本先确认眼镜广播成功；名称准备失败先排查原生组件，不要反复改手机网络。

## 失败时怎样带回足够证据

| 现象 | 记录与下一步 |
| --- | --- |
| 广播名称准备失败 | 升级本包、运行 pair；回传眼镜错误文字和故障排查文档中的原生阶段日志 |
| 未看到 loaded release=0.3.1 | 先查安装与缓存，不继续重配 |
| 手机授权已收到、delivered=false | 看具体本机交接/云端验证错误；先恢复 Rokid 与有效网络 |
| 5000ms 超时 / IPC channel closed | 让 AIUI 保持前台，记录 watch；系统助手可联网不保证 AIUI API 可用，不仅凭 Android 路由或蓝牙状态判断 |
| 瞬时错误后恢复在线 | 保留前后日志，恢复后只发送一次；无需立刻重配 |
| 明确刷新 401 且一直未恢复 | 回传日志处理授权；不因纯超时重配 |
| 发送 200、有手机回复、无眼镜回复 | 回传 main 的 ACK、reply_parse、seq；确认是否 own_user_echo、文本是否 accepted |
| unlinked_main_message | 关联条件未满足，保留事件结构；不要取消所有会话过滤 |
| accepted 且有文本、屏幕没显示 | 回传会话截图，检查 UI 显示 |

回传：每轮 results ZIP、眼镜会话/错误页截图、手机对应会话截图（遮盖其他内容），以及电脑/眼镜/手机型号和版本、国家、网络类型、VPN 状态。明确区分“看到用户消息”与“助手真正回复”。

诊断不采集令牌、聊天正文、录音、账号邮件或完整 logcat；保留公开设备身份、内网 IP、消息/会话指纹。发出前可查看 report.json。

## 需要开发者对照时

菜单 2 的 matrix 依次比较 main/official/gadget/scoped/baseline 五种订阅/发送组合，只建立连接，不自动发消息。main 默认不指定发送 session_id；official 是旧侧会话对照。订阅 200 不能证明该模式接收真实回复。对照应每轮只发一条，保持网络条件一致。
